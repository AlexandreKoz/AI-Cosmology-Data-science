# CosmoSim File Naming Conventions

- C++ headers: `snake_case.hpp`
- C++ sources: `snake_case.cpp`
- Tests: `test_<feature>.cpp`
- Run artifact root: `runs/run_<utc_yyyymmddThhmmssZ>_<short_gitsha>/`
- Checkpoints: `chkpt_step_<8-digit>.h5`
- Manifest: `run_manifest.yaml`
- Performance logs: `perf_step_<8-digit>.csv`
